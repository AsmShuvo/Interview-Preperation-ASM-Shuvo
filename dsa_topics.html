DSA Topic List By ASM Shuvo

A comprehensive roadmap for mastering Data Structures and Algorithms.

1. String

  • Learn all the string functions & operations.
  • Pattern matching basics.
  • String manipulation techniques.

2. Complexity Analysis

  • Big O Time Complexity for all algorithms.
  • Space Complexity analysis.
  • Best, Worst, and Average cases.

3. Basic Bitmasking

  • Bitwise operators: AND, OR, XOR, NOT, Shifts.
  • Setting, clearing, and toggling bits.
  • Checking if a bit is set.

4. Basic Recursion & Visualization

  • Recursion Tree visualization.
  • GCD (Greatest Common Divisor).
  • LCM (Least Common Multiple).

5. Number Theory Basics

  • Primes & Sieve of Eratosthenes.
  • Prime Factorization.
  • Modularity Basics (Modulo Arithmetic).

6. Heap Visualization

  • Heap Insertions (Up-Heapify).
  • Heap Deletions (Down-Heapify).
  • Max-Heap vs Min-Heap properties.

7. STL & Built-in Functions

  • Set, Unordered Set O(log N) / O(1)
  • Map, Unordered Map O(log N) / O(1)
  • Multimap, Multiset, Queue, Deque, Stack.
  • Find in array vs Find in set complexities.

8. Binary & Ternary Search

  • Binary Search (STL: lower_bound, upper_bound).
  • Binary Search on Answer.
  • Ternary Search (Unimodal functions).

9. Sorting Algorithms

  • Simple: Bubble, Selection, Insertion.
  • Advanced: Merge Sort, Quick Sort.
  • Implementation & Complexity (Best, Avg, Worst).
  • Stability & Comparison-based vs Non-comparison.

10. Core Techniques

  • Two Pointers (Opposite & Same direction).
  • Sliding Window Problems (Fixed & Variable).
  • Prefix Sum / Prefix Count arrays.

11. Combinatorics & Exponentiation

  • Binary Exponentiation O(log N)
  • NCR (Combinations) Calculation.
  • NPR (Permutations) Calculation.

12. Graph Theory

  • Adjacency Matrix vs List: When to use what.
  • DFS vs BFS: Comparison & Complexity.
  • Graph coloring & Bipartite Graph check.
  • Connected & Strongly Connected Components (SCC).
  • Cycles: Directed vs Non-Directed.
  • Topological Sort: DFS-based vs Kahn's Algorithm.
  • Shortest Path: Dijkstra, Bellman-Ford, Floyd-Warshall.Complexity, Comparision & Limitations
  • Dijkstra vs BFS comparison.

13. Tree

  • Traversals: Inorder, Preorder, Postorder.
  • Types of Trees
  • Types of Binary Trees.

14. Dynamic Programming (DP)

  • 0/1 Knapsack problem.
  • Longest Common Subsequence (LCS).
  • Longest Increasing Subsequence (LIS).
  • DP vs Greedy: When to use which approach.

16. Linked List

  • Singly & Doubly Linked List.
  • Insert/Delete implementations & Complexity.
  • Linked List vs Array: Comparison of operations.
